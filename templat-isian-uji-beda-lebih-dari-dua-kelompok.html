2

Ringkasan data (analisis deskriptif)

Panduan Jamovi ⌄
  1. Klik tab Analyses → Exploration → Descriptives.
  2. Masukkan variabel numeris ke kotak Variables dan variabel kategoris ke kotak Split by.
  3. Pada menu dropdown, ubah Variables across columns menjadi Variables across rows.
  4. Pada panel Statistics, tercentang opsi berikut dan matikan opsi lain:
Sample Size
  • N
Central Tendency
  • Mean
  • Median
Dispersion
  • Std. deviation
  • Minimum
  • Maximum

Ambil tangkapan layar tabel Descriptives yang terbentuk, lalu unggah di bawah ini.

Uji kesetaraan varians antar­kelompok

Baris ini hanya bisa diisi jika data terdistribusi normal di semua kelompok.

Panduan Jamovi ⌄
  1. Klik tab Analyses → ANOVA → One-Way Anova.
  2. Masukkan variabel numeris ke kotak Dependent Variables dan variabel kategoris ke kotak Grouping Variable.
  3. Pada panel utama, tercentang opsi berikut dan matikan opsi lain:
Assumption Checks
  • Homogeneity test
  • Normality test
  • Q-Q Plot

Ambil tangkapan layar tabel pada Assumption Checks dan diagram Q-Q Plot, lalu unggah di bawah ini.

Ukuran efek uji omnibus

Panduan Jamovi ⌄

Jika menggunakan uji ANOVA (Fisher maupun Welch)

  1. Klik tab Analyses → ANOVA → ANOVA.
  2. Masukkan variabel numeris ke kotak Dependent Variable dan variabel kategoris ke kotak Fixed Factors.

Jika menggunakan uji Kruskal-Wallis

  1. Masih di menu One-Way ANOVA (Non-parametric), centang opsi berikut:
Effect Size
  • ε²

Uji lanjutan (post-hoc)

Baris ini hanya bisa diisi jika keputusan adalah tolak H₀.

Panduan Jamovi ⌄

Jika menggunakan uji ANOVA (Fisher maupun Welch)

  1. Buka panel Post-Hoc Tests, lalu centang opsi yang sesuai (lihat pilihan di bawah panduan ini).
  2. Pastikan opsi ini tercentang:
Statistics
  • Mean difference
  • Report significance
  • Flag significant comparisons

Jika menggunakan uji Kruskal-Wallis

  1. Masih di menu One-Way ANOVA (Non-parametric), centang opsi pada Post Hoc Tests (lihat pilihan di bawah panduan ini).

Apa pun jenis uji lanjutan yang dipilih, ambil tangkapan layar tabel yang terbentuk, lalu unggah di bawah ini.
